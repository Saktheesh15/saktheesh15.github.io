# Saktheesh Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript, designed to showcase your skills and projects professionally.

## 🚀 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations
- **Easy Updates**: Simply replace files in the `assets` folder to update content
- **Resume Modal**: Interactive resume preview with download options
- **Contact Form**: Functional contact form that opens email client
- **Smooth Scrolling**: Enhanced navigation experience
- **Performance Optimized**: Fast loading with lazy loading and optimizations

## 🔄 How to Update Your Portfolio

### 1. Update Profile Photo
- Replace `assets/images/profile.jpg` with your photo
- Recommended size: 400x400px or square aspect ratio
- Supported formats: JPG, PNG, WebP

### 2. Update Project Images
- Replace `assets/images/project1.jpg` through `project4.jpg` with your project screenshots
- Recommended size: 800x600px or 16:9 aspect ratio
- Make sure images are high quality and showcase your work well

### 3. Update Resume Files
- Replace `assets/Saktheesh_Software_developer_Resume.pdf` with your software developer resume
- Replace `assets/Saktheesh_Data_Engineer_Resume.pdf` with your data engineer resume
- Keep the same filenames for the download links to work

### 4. Update Content
- Edit `index.html` to update:
  - Personal information (name, email, phone, location)
  - Project descriptions and links
  - Skills and technologies
  - Work experience details
  - About section content

## 🌐 Deployment Options

### GitHub Pages (Recommended)
1. Create a new repository named `yourusername.github.io`
2. Upload all files to the repository
3. Enable GitHub Pages in repository settings
4. Your site will be live at `https://yourusername.github.io`

### Netlify
1. Drag and drop the entire folder to Netlify
2. Your site will be automatically deployed
3. You can connect it to GitHub for automatic updates

### Vercel
1. Import the project to Vercel
2. Deploy with one click
3. Connect to GitHub for continuous deployment

## 🎨 Customization

### Colors
The website uses a blue color scheme. To change colors:
1. Open `styles.css`
2. Find color variables (e.g., `#2563eb` for blue)
3. Replace with your preferred colors

### Fonts
The website uses Inter font family. To change fonts:
1. Update the `font-family` property in `styles.css`
2. Add Google Fonts link in `index.html` if needed

### Layout
- Modify `styles.css` to adjust spacing, sizes, and layout
- Update grid layouts in the CSS for different arrangements
